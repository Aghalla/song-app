# 🎵 Song - پلتفرم موسیقی آنلاین

یک وب‌اپلیکیشن موسیقی آنلاین به سبک اسپاتیفای، ساخته شده با جنگو. کاربران می‌تونن موسیقی آپلود کنن، آلبوم بسازن و آهنگ‌های همدیگه رو گوش بدن.

## امکانات

### پخش و گوش دادن
- پخش آنلاین موسیقی با کیفیت بالا
- نمایش کاور آلبوم و اطلاعات آهنگ
- پیشنهاد آهنگ‌های مشابه بر اساس ژانر و هنرمند

### آپلود و مدیریت
- آپلود فایل MP3 با کاور خودکار از متادیتای فایل
- ساخت آلبوم و اضافه کردن آهنگ به آلبوم
- حذف و ویرایش آهنگ‌ها و آلبوم‌ها

### تعامل اجتماعی
- لایک کردن آهنگ‌ها
- سیو کردن آلبوم‌های مورد علاقه
- فالو و آنفالو کردن کاربران
- مشاهده پروفایل کاربران و آهنگ‌های آپلود شده

### جستجو و دسته‌بندی
- جستجوی پیشرفته آهنگ، هنرمند، آلبوم و کاربر
- فیلتر کردن بر اساس ژانر موسیقی
- مرتب‌سازی بر اساس جدیدترین، قدیمی‌ترین و محبوب‌ترین

### حساب کاربری
- ثبت‌نام و ورود
- ویرایش پروفایل (عکس پروفایل، بایو)
- بازیابی رمز عبور با کد تایید (ایمیل)
- رابط کاربری کاملاً فارسی

## نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.12+
- PostgreSQL
- pip

### مراحل نصب

1. **کلون کردن پروژه**
```bash
git clone https://github.com/Aghalla/song-app.git
cd song-app
```

2. **ساخت محیط مجازی**
```bash
python -m venv .venv
# ویندوز
.venv\Scripts\activate
# لینوکس/مک
source .venv/bin/activate
```

3. **نصب وابستگی‌ها**
```bash
pip install -r requirements.txt
```

4. **ساخت فایل .env**
فایل `.env.example` رو کپی کنید و نامش رو به `.env` تغییر بدید:
```bash
cp .env.example .env
```
سپس مقادیر دیتابیس و ایمیل رو توی فایل `.env` پر کنید.

5. **اجرای مایگریشن‌ها**
```bash
python manage.py migrate
```

6. **ساخت ادمین**
```bash
python manage.py createsuperuser
```

7. **اجرای سرور**
```bash
python manage.py runserver
```

## متغیرهای محیطی

فایل `.env` رو با این مقادیر پر کنید:

| متغیر | توضیح |
|--------|-------|
| `DATABASE_ENGINE` | موتور دیتابیس (پیش‌فرض: sqlite3) |
| `DATABASE_NAME` | نام دیتابیس |
| `DATABASE_USER` | نام کاربری دیتابیس |
| `DATABASE_PASSWORD` | رمز عبور دیتابیس |
| `DATABASE_PORT` | پورت دیتابیس |
| `EMAIL_HOST_USER` | ایمیل ارسال‌کننده (برای کد تایید) |
| `EMAIL_HOST_PASSWORD` | رمز عبور اپلیکیشن ایمیل |
